# Custom hero abilities

Canonical specification: docs/HEROES-AND-ABILITIES.md. All fifteen heroes receive one Z-key signature spell, custom IDs AK00–AK14 in hero selection order. Shared authored values are 700 range, 350 area radius, 70 mana, and 30-second cooldown. The same document records each effect, each hero's native ability IDs, level-100/ten-rank progression, and race-sensitive targeting rules.

Code/object data is not live proof. Cast and inspect every ability in current-build Warcraft III before calling its ID, icon, target rules, or effects verified.
